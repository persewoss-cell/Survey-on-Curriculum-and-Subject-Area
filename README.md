# 학교자율시간 실시간 설문

연수 현장에서 참가자는 휴대폰으로 익명 응답하고, 강사는 빔프로젝터 화면에서 결과 막대그래프가 실시간으로 올라가는 것을 보여 주는 1회용 설문 사이트입니다.

| 주소 | 용도 |
|---|---|
| `https://(내주소).vercel.app/` | **참가자용 응답 화면** (이 주소를 QR 코드로 만들어 보여 주세요) |
| `https://(내주소).vercel.app/results` | **발표자용 결과 화면** (빔프로젝터에 띄우기) |

- 같은 사람이 여러 번 응답할 수 있습니다(제출 후 "한 번 더 응답하기").
- 결과 화면은 2초마다 자동으로 갱신됩니다.
- 결과 화면 오른쪽 위 **전체 초기화** 버튼을 누르면 모든 응답이 지워집니다(연수 시작 전에 눌러 두세요).
- 문항·선택지는 `lib/options.js` 한 파일에서 고칠 수 있습니다.
- 맨 위 **학교 정보(필수)**: 지역(광주 5개 구 + 전남 22개 시·군)과 학교명('초등학교' 앞부분만 입력). 결과 화면에는 나오지 않습니다.
- 결과 화면 오른쪽 위 **다운로드 아이콘**을 누르면 학교 일괄 등록 양식(`templates/school-bulk-template.xlsx`)에 응답한 학교를 채운 엑셀을 받습니다. 지역·학교명이 모두 같으면 한 줄로 합치고, 비밀번호는 모두 `gkrwktl1@`입니다. 양식을 바꾸면 `node scripts/embed-template.js`를 실행하세요.
- 문항은 4개입니다. Q1에서 '미운영'을 고르면 바로 제출되고, '운영'을 고른 분만 Q2~Q4에 응답합니다.
- 결과 화면 제목 옆 N은 전체 응답 수입니다. Q2~Q4의 비율은 '운영' 응답 수를 기준으로 계산합니다.

## 처음 배포하기 (약 10분, 모두 무료)

코드는 이미 GitHub 저장소에 올라가 있으니 Vercel에서 이 저장소를 가져오기만 하면 됩니다.

### 1단계. Vercel에 배포하기
1. <https://vercel.com>에서 **Continue with GitHub**로 가입하거나 로그인합니다(Hobby 무료 플랜).
2. **Add New… → Project**를 누릅니다.
3. 목록에서 `Survey-on-Curriculum-and-Subject-Area` 저장소 옆 **Import**를 누릅니다.
4. 설정은 그대로 두고 **Deploy**를 누릅니다. 1~2분 뒤 주소(`https://○○○.vercel.app`)가 생깁니다.

> 이 상태에서도 화면은 열리지만, 아직 저장소(Redis)가 없어서 응답이 서로 공유되지 않습니다. 반드시 2단계를 하세요.

### 2단계. 저장소(Redis) 연결하기 — 클릭만 하면 됩니다
1. Vercel에서 방금 만든 프로젝트로 들어가 위쪽 **Storage** 탭을 누릅니다.
2. **Create Database**(또는 **Browse Marketplace**)에서 **Upstash → Redis**를 고르고 **Continue**를 누릅니다.
3. 무료 플랜(Free)을 고르고 지역은 **Tokyo**나 **Seoul**처럼 가까운 곳으로 정한 뒤 **Create**를 누릅니다.
4. 연결할 프로젝트를 묻는 화면이 나오면 이 프로젝트를 선택하고 **Connect**를 누릅니다.
   → `KV_REST_API_URL`, `KV_REST_API_TOKEN` 같은 환경변수가 **자동으로** 들어갑니다. 직접 입력할 값은 없습니다.
5. 환경변수는 다시 배포해야 반영됩니다. **Deployments** 탭에서 가장 위 배포의 **⋯ → Redeploy**를 누릅니다.

### 3단계. 확인하기
1. 노트북에서 `https://○○○.vercel.app/results`를 엽니다.
2. 휴대폰으로 `https://○○○.vercel.app/`에 들어가 한 번 응답합니다.
3. 2초 안에 결과 화면 막대가 올라가면 성공입니다. 확인한 뒤 **전체 초기화**를 누릅니다.

### 4단계. QR 코드
결과 화면 오른쪽 아래에 설문 QR이 자동으로 표시됩니다(결과 화면을 연 주소 기준). **QR 이미지 저장** 버튼으로 PNG 파일을 받을 수 있고, `qr/` 폴더에도 완성된 QR 이미지가 있습니다.

직접 만들고 싶다면:
`https://○○○.vercel.app/` 주소로 QR 코드를 만들어 슬라이드에 넣습니다.
(네이버 QR코드, 크롬 주소창의 "공유 → QR 코드 만들기" 등 무료 도구를 쓰면 됩니다.)

## 연수가 끝난 뒤
- 결과 화면에서 **전체 초기화**를 누르면 응답이 모두 삭제됩니다.
- 다시 쓸 일이 없다면 Vercel의 Settings 맨 아래 **Delete Project**로 사이트를 지우고, Storage의 Redis도 삭제하면 됩니다.

## 참고
- 응답에는 이름이나 기기 정보 같은 개인정보가 저장되지 않습니다. 저장되는 것은 Q1·Q2 선택 수, 기타 입력 문구, 입력 시각입니다.
- 서버는 정해진 선택지만 받습니다. 기타 문구는 40자로 제한되고 화면에 표시할 때 HTML이 이스케이프됩니다.
- 결과 화면의 초기화 버튼에는 비밀번호가 없습니다. `/results` 주소를 아는 사람은 누구나 누를 수 있으니 결과 화면 주소는 참가자에게 공유하지 마세요.

## 글꼴
화면 글꼴은 네이버의 나눔스퀘어라운드(SIL OFL 1.1, 무료)이며 `public/fonts`에 들어 있습니다.

## 내 컴퓨터에서 미리 보기 (선택)
Node.js 20 이상이 필요합니다.
```bash
npm install
npm run dev
```
`http://localhost:3000`과 `http://localhost:3000/results`를 엽니다. Redis 설정이 없으면 응답이 메모리에 저장되며, 서버를 끄면 사라집니다.
